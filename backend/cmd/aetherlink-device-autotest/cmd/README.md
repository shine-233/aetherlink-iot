# cmd

## 目录职责

承载设备自动测试工具的命令行入口目录。当前只有 `autotest` 子命令，用于按配置加载设备、连接 MQTT broker，并触发基础上报冒烟流程。

## 文件关系

`autotest/main.go` 调用 `internal/config` 加载 YAML，通过 `internal/device` 创建直连或网关设备，并使用 `internal/utils` 生成脱敏遥测、属性和事件测试数据。

## 重点文件

| 文件 | 说明 |
| --- | --- |
| `autotest/main.go` | CLI 参数、日志初始化、设备连接、订阅和测试模式分派。 |

## 审查建议

把这里视为手动冒烟入口，不要把它等同于完整外部集成测试。审查时确认 CLI 默认配置路径、退出码、日志和测试模式是否符合实际运维使用方式。
