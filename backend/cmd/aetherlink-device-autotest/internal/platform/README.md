# internal/platform

## 目录职责

封装自动测试与真实平台的外部交互，包括 HTTP API 下行操作和 PostgreSQL 结果查询。

## 文件关系

`api_client.go` 被下行控制、属性设置和命令测试调用。`db_client.go` 被直连和网关测试用于验证遥测、属性、事件和下行日志是否落库。

## 重点文件

| 文件 | 说明 |
| --- | --- |
| `api_client.go` | API 请求封装、认证头、控制/属性/命令下发。 |
| `db_client.go` | 数据库连接和验证查询。 |

## 审查建议

检查 API 路径、请求体字段大小写、响应 code 语义和数据库表结构是否仍与平台一致。注意多个查询取最新记录，可能需要更严格的时间窗口或 message_id 过滤。
