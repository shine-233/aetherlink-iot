# 后端配置目录

`backend/configs` 保存后端启动需要读取的配置模板、消息文案和少量运行资产。

## 文件说明

- `conf.example.yml`：安全示例配置，使用 `CHANGE_ME_*` 占位符，适合作为部署前的参考模板。
- `conf-dev.yml`：开发环境模板，复制为本地配置后再按机器环境修改。
- `conf-localdev.yml`：本地开发配置，用于本机调试；提交前需要确认没有真实密码或私有地址。
- `conf.yml`：默认配置入口，通常由后端启动流程读取。
- `casbin.conf`：Casbin 权限模型定义，描述主体、资源、动作和角色匹配规则。
- `messages.yaml` / `messages_str.yaml`：错误码、界面文案或接口返回消息的中英文映射。
- `rsa_key/`：RSA 公私钥目录，详见子目录 README。

## 维护注意

- 不要把真实数据库密码、Redis 密码、MQTT 账号、JWT 密钥或生产私钥写入模板。
- 调整配置 key 时，要同步检查读取这些 key 的初始化代码和配置结构体。
- 只做文档注释时不要改配置值，避免影响本地或演示环境启动行为。
