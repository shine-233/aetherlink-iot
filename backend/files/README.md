# 后端文件资产

本目录用于存放后端运行或接口展示需要读取的静态文件资产。

## 当前内容

- `logo.png`：后端侧保留的默认标识图片资产。

遥测持久兜底不属于本公开文件目录。其默认位置是 `../data/telemetry-spool/`，Compose 使用独立的 `backend-telemetry-spool` 持久卷；配置校验会拒绝 `files/` 本身及其子目录，避免原始遥测值被 `/files/*filepath` 下载路由暴露。

## 维护注意

- PNG、证书、压缩包等二进制文件不要用文本方式改写，避免损坏文件内容。
- 如果后续新增可文本维护的说明、模板或配置文件，请同步补充用途、来源和是否可公开发布。
- 本目录处于公开文件服务边界内，不得存放 telemetry spool、日志或其他包含租户原始数据的运行时文件。导出文件或上传文件也不应直接提交，除非它们是已经确认可公开的示例资产。
