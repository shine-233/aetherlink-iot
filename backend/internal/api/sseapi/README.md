# SSE API 入口

`backend/internal/api/sseapi` 保存基于 SSE 的接口处理入口，用于向前端或调用方推送持续事件流。

## 目录职责

- 处理 SSE 连接建立、事件推送入口和相关响应组织。
- 为需要持续订阅更新的前端场景提供流式 API 支持。

## 维护边界

- SSE 的事件名、消息结构和连接行为属于客户端可见契约。
- 修改事件推送节奏、格式或错误路径时，需要同步核对前端消费逻辑和自动化预期。

## 审查建议

- 问题：流式接口比普通 HTTP 更容易出现“看起来没报错、实际上消费失效”的问题。
- 改进：在代码与 README 中明确事件格式、连接关闭语义和兼容边界。
- 预期效果：前后端联调与后续排障更容易。
