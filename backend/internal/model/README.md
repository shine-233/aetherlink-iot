# 后端模型层

`backend/internal/model` 保存后端内部使用的请求、响应、数据库和领域结构体，是 API、Service、DAL 之间共享的数据契约层。

## 目录职责

- 定义请求与响应结构。
- 定义数据库模型与部分领域结构。
- 为多层协作提供统一的数据载体。

## 维护边界

- 字段名、JSON tag、数据库 tag 和兼容结构一旦变动，通常会同时影响前端、自动化、DAL 和持久化行为。
- 变更模型前，应先判断它是“领域变更”还是“仅表现层变更”，避免随意扩散。

## 审查建议

- 问题：模型层小改动往往有大影响，尤其是 tag、可空字段和兼容字段。
- 改进：在 README 和文件头里明确哪些模型是高敏感共享契约。
- 预期效果：减少字段漂移，提升跨层修改时的可控性。
