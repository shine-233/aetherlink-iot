# 后端查询生成层

`backend/internal/query` 保存 GORM 相关的查询辅助代码，主要由生成流程产出，供 `dal/` 和其他内部层按类型安全方式组织查询条件。

## 目录职责

- 提供数据库实体对应的查询字段、表达式和链式查询辅助。
- 作为生成代码使用，减少手写字段名和条件拼装的出错概率。

## 维护边界

- 默认不要手工编辑这里的生成文件。
- 如需调整字段、结构或生成策略，应优先更新生成来源和生成流程，再重新生成。

## 审查建议

- 问题：维护者容易把生成层当成普通手写代码直接修改。
- 改进：明确“可生成、可再生、默认不手改”的规则，并同步根目录生成文件文档。
- 预期效果：减少手改生成代码导致的回归和后续覆盖问题。
