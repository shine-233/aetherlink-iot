# 协议插件服务层

`backend/internal/service/protocol_plugin` 保存协议插件相关的服务层逻辑，用于承接设备协议扩展、插件侧能力编排和与后端业务服务的桥接。

## 目录职责

- 协调协议插件与后端业务服务之间的交互。
- 封装协议扩展能力的服务层逻辑，而不是底层插件实现细节本身。

## 维护边界

- 具体协议解析或底层插件行为应继续留在更贴近插件/适配器的实现层。
- 这里若改动了协议字段、插件标识或回调语义，后续需要同步核对兼容文档和相关调用方。

## 审查建议

- 问题：协议插件目录容易隐藏外部契约前提。
- 改进：把输入输出、兼容边界和失败行为在 README 与文件头里说明清楚。
- 预期效果：后续协议扩展或替换时更容易评估影响面。
