# backend/pkg/constant

## 目录定位

`backend/pkg/constant` 是后端公共常量包，集中保存跨模块复用的角色、设备类型、表单类型、命令状态和功能开关值。

## 文件用途

- `constant.go`：定义系统管理员、租户管理员、租户用户等角色常量，以及设备接入类型、手自动模式、命令响应状态、设备模型来源、表单类型和功能启停标记。

## 依赖关系

本目录当前不依赖其他项目包，是上层 API、service、DAL、公共工具包和测试代码的基础输入。由于常量值可能进入数据库、前端判断或 API 自动化断言，修改时需要同步检查外部契约。

## 审查发现

- 常量值混合了权限、设备、命令、表单和系统功能多个领域，查找方便但领域边界不够清晰。
- 部分常量值属于持久化或接口可见值，改名或改值会造成兼容性风险。
- 注释已说明大部分含义，但还缺少“哪些常量允许新增、哪些不能改值”的契约说明。

## 重构建议

后续可按领域拆分文件，例如 `roles.go`、`device.go`、`form.go`、`command.go`，并为持久化/外部可见常量补充契约测试或枚举说明。

## 验证建议

修改本目录后运行依赖这些常量的窄范围测试，例如 `cd backend; go test ./pkg/common ./pkg/constant -count=1`。若改动角色、设备类型或表单值，还应补充对应 service/API 合同测试。
