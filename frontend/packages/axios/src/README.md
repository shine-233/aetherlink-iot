# axios 请求封装源码

## 目录定位
本目录提供 `@aetherlink/axios` 的核心源码，是前端请求层的 Axios 适配封装，负责统一请求实例、请求选项、重试策略、响应映射和取消控制。

## 主要文件
- `index.ts`：创建扁平请求实例，串联请求/响应拦截、业务成功判断、错误映射、重试与取消。
- `options.ts`：生成默认请求选项、Axios 基础配置和 `axios-retry` 配置。
- `shared.ts`：提供 Content-Type 读取、HTTP 状态判断和成功响应判定等共享工具。
- `constant.ts`：维护请求 ID 与后端错误码等跨文件常量。
- `type.ts`：集中定义请求配置、响应映射、错误处理和实例能力类型。

## 依赖关系
依赖 `axios`、`axios-retry`、`qs` 和 `@aetherlink/utils` 的 `nanoid`。上层业务通常通过 `@aetherlink/hooks` 或应用请求模块间接使用这里的请求实例。

## 审查发现
当前实现属于轻量请求基础设施，职责集中但入口文件承担了较多流程编排。文件内已有英文函数注释，但缺少目录级说明和中文文件头，排查业务请求链路时需要跨文件阅读。

## 重构建议
后续可在不改变外部 API 的前提下，把错误归一化、取消控制和响应映射拆成独立内部模块，并补充每类错误的最小单元测试。

## 验证建议
优先执行 targeted eslint：`pnpm exec eslint packages/axios/src --ext .ts`。若改动请求行为，再补充请求拦截、业务失败、HTTP 失败、重试与取消场景的单元测试。
