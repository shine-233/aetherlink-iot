# 色板工作区包

`frontend/packages/color-palette` 保存前端共享色板数据和颜色辅助能力，用于主题、图表、状态色和可视化组件。

## 目录定位

- 集中维护品牌色、语义色、图表色和可复用颜色 token。
- 为主题配置、组件样式和可视化图表提供稳定导出。
- 减少页面内散落的硬编码颜色。

## 关键关系

- 导出名称会被主题、组件和图表配置引用，随意改名会造成大范围样式回归。
- 色值调整会影响可访问性、暗浅色背景适配和数据可视化区分度。
- 若颜色 token 被构建脚本生成，需要和生成源保持一致。

## 维护注意事项

- 不要在业务页面新增同义硬编码颜色，优先复用本包 token。
- 修改语义色时要检查按钮、告警、状态标签和图表对比度。
- 保持导出名稳定；必须重命名时应提供迁移说明。
- 颜色新增要说明用途，避免出现多个近似但语义不清的色值。

## 代码审查与重构建议

- 问题：色板缺少语义边界会导致主题长期漂移。
- 改进方案：按品牌色、状态色、图表色、背景/边框色分层维护。
- 实施步骤：先清点重复色值，再合并同义 token，最后验证主页面和可视化图表。
- 预期效果：视觉一致性更强，主题调整更安全。
