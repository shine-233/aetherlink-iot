# color-palette 调色板源码

## 目录定位
本目录提供 `@aetherlink/color-palette` 的颜色识别与调色板生成能力，用于根据输入色值匹配颜色名称、最近色板和同色系梯度。

## 主要文件
- `index.ts`：对外导出获取色板、色板族和颜色名称的主入口。
- `color.ts`：封装 `colord` 的颜色校验、格式转换与 DeltaE 计算。
- `name.ts`：基于内置颜色名称 JSON 计算最近颜色名。
- `palette.ts`：基于默认调色板计算最近色板族和派生色板。
- `type.ts`：定义色板编号、色板项、色板族等类型。
- `json/`：保存内置色板和颜色名称数据。

## 依赖关系
主要依赖 `colord` 及其 `lab` 插件，并读取本目录下的 JSON 数据。上层通过包入口使用，通常不直接依赖内部 JSON 结构。

## 审查发现
算法与数据耦合较紧，当前目录缺少中文说明，调用者难以判断“最近色名”和“最近色板”的计算边界。

## 重构建议
可逐步把默认数据加载和算法函数解耦，允许测试注入小型色板数据，降低单测对完整 JSON 的依赖。

## 验证建议
优先执行 `pnpm exec eslint packages/color-palette/src --ext .ts`。行为改动建议补充有效/无效颜色、RGB/HSL/HEX 转换、最近色名和最近色板的固定样例测试。
