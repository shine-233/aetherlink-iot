# materials 组件库目录

## 目录定位

`frontend/packages/materials/src/libs` 汇总材料库内可复用的基础 UI 组件，是业务前端和可视化编辑器之间的组件资产层。这里的组件应保持独立、可嵌入、少业务假设。

## 文件用途

- `admin-layout/` 提供后台布局类材料。
- `page-tab/` 提供可关闭页签组件，已有子目录 README 说明具体实现。
- `simple-scrollbar/` 提供轻量滚动容器材料。

## 维护边界

本目录只维护材料库组件和组件导出关系，不应直接依赖业务页面、后端接口或运行时 store。新增材料时，应优先放入独立子目录，并保持 props、事件和样式变量可被外部明确审查。

## 审查发现

当前父目录缺少总览说明，容易让维护者只阅读单个组件 README，而忽略材料库与业务页面之间的边界。子组件职责相对清晰，适合继续按组件粒度维护。

## 重构建议

后续可以补一层统一导出索引和组件契约表，列出每个材料的 props、事件、样式变量和适用场景，避免业务侧重复阅读组件源码确认能力。

## 验证建议

材料变更后优先运行材料库相关类型检查、组件单测和引用该材料的页面级 smoke 测试。仅新增 README 时无需运行前端构建。
