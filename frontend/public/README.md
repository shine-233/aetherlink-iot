# 公共静态资源目录

## 用途

这里存放会被 Vite 原样复制到构建产物根路径的公共资源，例如站点图标和公开访问的品牌素材。适合放置不需要经过打包器处理、路径必须稳定的文件。

## 命名约定

- 文件名使用小写短横线或既有产品约定，避免空格和临时后缀。
- 子目录按业务或品牌来源划分，例如 `rdi`。
- 对外路径稳定的资源不要随意改名，避免部署后引用失效。

## 维护注意事项

- 不要在这里放源码、测试数据或含敏感信息的文件。
- 图片替换前确认页面、邮件模板或外部集成是否直接引用了公共路径。
- 资源体积过大时优先压缩图片或迁移到按需加载的 `src/assets`。

## 可删除或压缩建议

- 长期未被 HTML、CSS、配置或后端模板引用的资源可以列入删除候选，但删除前需要全仓搜索确认。
- PNG/JPG 更新时建议使用无损压缩；SVG 更新时建议移除编辑器元数据。
