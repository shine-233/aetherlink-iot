# RDI 公共资源目录

## 用途

这里存放 RDI 相关的公共品牌资源，例如登录、头像或展示场景需要直接通过公共路径访问的图片。

## 命名约定

- 使用能表达用途的英文文件名，例如 `logo.png`、`default_avatar.png`。
- 已被外部链接或配置引用的文件名保持稳定。
- 新增资源应避免使用版本号、临时说明或中文文件名。

## 维护注意事项

- 替换品牌资源前确认尺寸、透明背景和页面显示比例。
- 不要改动二进制内容以外的引用路径，除非同步验证所有调用方。
- 若资源只在组件内使用，优先考虑迁移到 `src/assets` 并走打包优化。

## 可删除或压缩建议

- 未被公共路径引用的旧图可在全仓搜索确认后删除。
- PNG 可做无损压缩；头像类图片应控制尺寸，避免把大图直接作为默认头像。
