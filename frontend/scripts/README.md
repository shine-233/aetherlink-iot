# 前端脚本目录

## 用途

这里放置前端开发和质量维护脚本，例如提交前质量检查、批量清理 `console.log` 等自动化辅助工具。

## 命名约定

- 脚本文件使用短横线命名，例如 `dev-quality-check.js`。
- 可直接执行的 Node 脚本保留 `#!/usr/bin/env node`。
- 脚本职责要单一，复杂流程应拆成清晰函数并在 README 中说明入口。

## 维护注意事项

- 不要让脚本默认格式化整个前端或修改二进制资源。
- 批量改写脚本必须先说明扫描范围，并尽量提供 dry-run 或可审计输出。
- 修改脚本后至少运行 targeted eslint 或对应轻量命令，确认没有语法和 lint 回归。
