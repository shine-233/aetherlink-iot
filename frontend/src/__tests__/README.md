# 前端顶层测试目录

## 目录定位

`frontend/src/__tests__` 存放靠近前端入口层的测试组织目录，用于承接全局 setup、跨模块单测或顶层行为契约检查。

## 文件用途

- `unit/` 保存顶层单元测试分组。

## 维护边界

本目录不应沉淀具体业务模块的大量细节测试。模块私有测试优先放在对应模块旁边的 `__tests__` 或同目录 `.test.ts` 文件中，避免顶层测试变成难以归属的集合。

## 审查发现

当前目录结构很轻，适合作为全局测试入口说明。后续若继续增加文件，需要明确每个测试为什么不能放回模块目录。

## 重构建议

若顶层测试数量增长，建议按 `contracts/`、`integration/`、`unit/` 再拆分，并在 README 中维护每组测试的运行命令和覆盖边界。

## 验证建议

修改测试工具或全局 fixture 后，运行对应 Vitest 目标和受影响模块的单测。仅新增 README 时做目录扫描即可。
