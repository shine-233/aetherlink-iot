# 前端静态资源目录

## 目录定位

`frontend/src/assets` 保存需要被前端源码直接引用的静态资源。它不同于 `public/` 的原样发布资源，通常会经过构建工具解析、打包或路径转换。

## 文件用途

- `data/` 保存前端本地数据资源，例如区域 JSON，已有子目录 README。
- `illustrations/` 保存异常页、权限页等可复用插画资源。
- `imgs/` 保存头像、物模型封面等位图资源。
- `svg-icon/` 保存菜单、设备状态、环境、地图、操作按钮等本地 SVG 图标。

## 维护边界

本目录只放源码引用的静态资产，不应存放运行时报告、截图归档、用户上传文件或构建产物。大体积资源进入仓库前应确认许可、体积和加载路径。

## 审查发现

子目录已经有更细 README，父目录只记录源码资产和发布资产的边界。该边界对后续清理构建产物很重要。

## 重构建议

后续可为图片、SVG 和 JSON 数据分别建立命名规范，并补充资源体积阈值和压缩要求，避免静态资产无意扩大首屏包体积。

## 验证建议

新增或替换资源后，检查引用路径、构建输出和浏览器实际加载结果。仅新增 README 时无需运行前端构建。
