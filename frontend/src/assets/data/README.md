# 静态数据资源目录

## 用途

这里存放前端随包发布的静态数据文件，例如地区行政区划 JSON。适合放置读多写少、无需接口实时更新的小型数据集。

## 命名约定

- 文件名使用数据主题加格式，例如 `china-region.json`。
- 数据字段应保持稳定，避免频繁调整结构导致调用方解析失败。
- 新增数据文件应在 README 中说明来源、更新时间和使用方。

## 维护注意事项

- JSON 不支持注释，维护说明放在 README，不要写进数据文件。
- 更新行政区划等数据时应注明来源和采集日期。
- 大型数据会增加首包或构建体积，优先考虑按需加载或接口化。

## 可删除或压缩建议

- 未被页面、工具函数或测试引用的数据文件可列入删除候选。
- 大 JSON 可评估字段裁剪、分区拆分或运行时按需加载。
