# 插画资源目录

## 用途

这里存放错误页、空状态、权限提示、横幅等界面插画，通常由页面直接作为视觉说明引用。

## 命名约定

- 文件名使用具体场景命名，例如 `not-found.svg`、`service-error.svg`。
- 同类插画保持统一风格、视图框和主色调。
- 新增资源应优先使用可缩放 SVG，除非确实需要位图细节。

## 维护注意事项

- 不要改动二进制或矢量内容本身，除非任务明确要求替换资源。
- SVG 中不应包含脚本、外链或不必要的编辑器元数据。
- 替换插画时检查暗色/亮色主题下的可读性。

## 可删除或压缩建议

- 未被路由页、异常页或组件引用的插画可列入删除候选。
- SVG 可使用 SVGO 类工具压缩，但压缩后需确认图形没有变形。
