# 图片资源目录

## 用途

这里存放前端通过模块导入使用的位图图片，例如默认封面、头像或页面展示素材。与 `public` 不同，这里的资源通常会经过构建工具处理。

## 命名约定

- 文件名使用小写短横线或已有业务命名，避免空格和临时后缀。
- 默认图使用 `default-*` 或既有约定，便于搜索替换。
- 同一业务类型的图片尽量放在同一目录内，不要散落到组件目录。

## 维护注意事项

- 不要在文档化任务中修改 PNG/JPG 等二进制内容。
- 替换图片前确认尺寸、透明通道、压缩质量和引用路径。
- 大图会影响构建产物体积，新增前应评估是否需要懒加载。

## 可删除或压缩建议

- 未被源码导入的图片可列入删除候选，但删除前需要全仓搜索文件名。
- PNG 可做无损压缩；展示图可按实际显示尺寸重新导出。
