# SVG 图标目录

## 用途

这里存放本地图标 SVG，供菜单、设备状态、环境传感器、地图、操作按钮等前端界面按名称引用。

## 命名约定

- 文件名使用英文语义名称，推荐小写短横线，例如 `air-temperature.svg`。
- 来自第三方图标集的文件可保留原始 PascalCase 名称，但新增时应优先贴近现有业务语义。
- 同一含义不要重复放多个相近图标，必要时在 README 中说明差异。

## 维护注意事项

- SVG 不应包含脚本、远程外链或无关元数据。
- 修改图标前确认是否被菜单配置、动态图标选择器或物模型引用。
- 颜色若由 CSS 控制，SVG 内部应尽量使用可继承的填充方式。

## 可删除或压缩建议

- 未被源码、菜单配置或图标选择器引用的 SVG 可列入删除候选。
- 压缩 SVG 时要保留 `viewBox`，压缩后检查图标尺寸和颜色是否正常。
