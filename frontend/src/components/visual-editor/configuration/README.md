# 可视化编辑器配置

`frontend/src/components/visual-editor/configuration` 保存可视化编辑器 widget 配置桥、状态管理器和配置类型，是编辑器配置持久化的核心目录。

## 目录定位

- 定义 widget 配置的读取、更新、默认值和兼容转换逻辑。
- 管理配置区与编辑器主状态之间的数据同步。
- 为导入导出、历史配置恢复和运行时预览提供一致的数据结构。

## 关键关系

- 配置类型要和后端/本地持久化 JSON 保持兼容。
- 默认值会影响新建 widget，也会影响旧配置缺字段时的 fallback。
- 状态更新语义会影响撤销、保存、预览和表单联动。
- 导入导出逻辑依赖字段名稳定，不能随意重命名。

## 维护注意事项

- 修改配置字段前先确认历史数据是否存在同名字段或旧格式。
- 对可选字段必须定义明确默认值，避免运行时出现 `undefined` 分支。
- 不要在配置层混入页面展示副作用，副作用应留给调用方。
- 大型配置迁移应先提供只读兼容，再考虑写回新格式。

## 代码审查与重构建议

- 问题：配置桥和状态管理如果缺少版本边界，后续扩展会不断累积兼容判断。
- 改进方案：引入配置 schema/version 概念，把默认值填充、旧数据迁移和 UI 更新拆开。
- 实施步骤：先列出现有字段与默认值，再补 migration 单测，最后用真实导入导出回放验证。
- 预期效果：widget 配置升级路径清晰，导入导出和历史恢复更稳定。
