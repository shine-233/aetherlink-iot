# 前端配置目录

## 用途

这里集中放置前端运行时配置的统一出口，例如安全配置、环境覆盖规则和配置模块元信息。业务代码需要读取全局配置时，应优先从本目录的出口文件引入，避免在页面或组件里散落硬编码。

## 命名约定

- `index.ts` 作为配置模块的统一导出入口。
- 子目录按配置领域命名，例如 `security` 表示安全相关配置。
- 新增配置项时优先使用清晰的英文键名，中文说明写在文件头、README 或必要注释里。

## 维护注意事项

- 配置默认值应保持可审计，涉及密钥、公钥、服务地址等敏感信息时要说明来源和覆盖方式。
- 不要在业务组件中重复定义本目录已有的配置常量。
- 新增配置后同步补充类型定义和 README 说明，便于后续排查运行时差异。
