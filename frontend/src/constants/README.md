# 前端常量目录

## 用途

这里集中维护前端复用常量，包括应用主题选项、业务枚举、公共开关、地图 SDK 地址和表单校验正则。页面、组件和工具函数需要共享固定值时，应优先复用本目录内容。

## 命名约定

- 文件按领域拆分，例如 `app.ts` 表示应用主题与登录模块，`business.ts` 表示业务枚举。
- 常量名使用大写下划线或清晰的语义化驼峰名，和现有调用习惯保持一致。
- 选项类常量通常以 `Record` 保存原始映射，再导出 `Options` 给 UI 使用。

## 维护注意事项

- 修改枚举值前要确认接口、国际化 key 和页面表单是否同步。
- 地图 SDK key 属于外部服务契约，替换前需确认环境和额度。
- 正则变更会影响表单校验，建议补充对应单元测试或至少记录输入样例。
