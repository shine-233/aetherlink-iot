# Data Architecture 核心说明

## 目录职责

该目录承载可视化编辑器的数据源配置体系，包括配置归一化、导入导出、执行链、运行时数据桥接与相关类型契约。

## 关键文件

- `DataFormatNormalizer.ts`：多种历史/运行时格式归一化入口。
- `VisualEditorBridge.ts`、`SimpleDataBridge.ts`：连接编辑器侧配置与运行时执行能力。
- `utils/`：导入导出、路径恢复、单数据源导入等兼容工具。

## 维护提示

- 这里的改动经常同时影响“配置能否保存”和“运行时能否正确取数”两条链路。
- 修改持久化结构或格式兼容逻辑前，务必先确认上下游契约。
