# Data Architecture Adapters

## 目录职责

维护配置版本适配和新旧数据结构转换逻辑，保障历史配置可以在当前数据架构中继续读取、升级或降级。

## 文件关系

- `ConfigurationAdapter.ts` 依赖 `types/enhanced-types.ts` 与基础数据源类型，负责版本检测和格式转换。
- `index.ts` 聚合适配器导出，供导入导出、配置管理和测试引用。
- 适配器输出需要与 `executors/` 可执行结构、`components/` 编辑结构保持一致。

## 重点文件

- `ConfigurationAdapter.ts`：配置版本检测、v1/v2 转换和标准数据项兼容的核心实现。
- `index.ts`：目录公共导出入口，负责稳定调用方导入路径。

## 审查建议

- 版本字段、数据项结构和默认值变更必须配套历史配置样本或迁移测试。
- 已支持字段应保持无损；增强类型无法表示的 HTTP 参数配置和未知插件类型必须明确阻断并暴露诊断信息，禁止静默丢弃。
- 新增适配规则时，同步检查导入导出、配置生成和执行器是否理解转换后的结构。
