# Common Parameter Templates

## 目录职责

维护动态参数编辑器使用的参数值模板注册和异步组件加载入口，帮助不同参数输入模式复用统一模板定义。

## 文件关系

- `index.ts` 定义模板类型枚举、模板配置结构和模板组件加载映射。
- 模板注册被 `components/common/DynamicParameterEditor.vue` 消费，用于切换手动输入、属性绑定、设备参数或组件模板等输入方式。
- 这里的模板类型需要与 `types/parameter-editor.ts` 中的参数编辑状态保持一致。

## 重点文件

- `index.ts`：参数模板注册表和异步加载入口，是新增参数输入模式时的主审查点。

## 审查建议

- 新增模板类型时，同步检查动态参数编辑器、参数类型定义和导入导出是否能保留该类型。
- 异步组件路径会影响打包和运行时加载，重命名文件前先确认引用。
- 避免把业务默认值写死在模板注册表中，优先由具体配置步骤或模板数据提供。
