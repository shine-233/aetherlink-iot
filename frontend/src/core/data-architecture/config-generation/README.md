# Data Architecture Config Generation

## 目录职责

维护根据组件数据需求和用户输入生成简化数据源配置的逻辑，用于降低配置表单到执行器结构之间的转换成本。

## 文件关系

- `SimpleConfigGenerator.ts` 依赖简化数据架构类型，生成可执行的简化配置；字段路径预览使用受限本地解析器，不执行任意代码。
- `index.ts` 提供稳定导出入口。
- 当前模块通过公共入口导出；调用方需要显式适配生成结果后再交给执行链或导入导出工具。

## 重点文件

- `SimpleConfigGenerator.ts`：简化配置生成核心实现，负责默认值、字段映射和用户输入归一。
- `index.ts`：配置生成能力的公共导出入口。

## 审查建议

- 生成字段变化要同步检查执行链、导入导出和类型定义。
- 默认值不能只满足 UI 展示，还要能被运行时执行器正确消费。
- 新增生成规则时，补充确定性测试和典型组件需求 fixture。
