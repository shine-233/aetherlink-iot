# Data Architecture Services

## 目录职责

维护数据架构中的服务型模块，当前主要是配置验证、模板管理和存储辅助能力。

## 文件关系

- `ConfigurationManager.ts` 使用数据架构类型，提供配置验证、模板注册和读取能力。
- 服务层应被组件或桥接器调用，但不应直接承担 Vue 展示状态。
- 测试文件验证配置管理服务的核心输入输出契约。

## 重点文件

- `ConfigurationManager.ts`：配置管理服务主实现。
- `ConfigurationManager.test.ts`：服务契约的单元回归测试。

## 审查建议

- 验证规则和默认模板变化会影响用户保存配置前的反馈。
- 服务层应明确副作用边界，避免同时管理 UI 状态和持久化逻辑。
- 新增存储或外部依赖时，补充失败场景和降级行为测试。
