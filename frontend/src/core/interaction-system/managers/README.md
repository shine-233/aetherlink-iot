# interaction-system 管理器目录

## 目录定位

`frontend/src/core/interaction-system/managers` 保存交互系统的管理器类代码，负责把 UI 组件、配置类型和运行时注册关系解耦。

## 文件用途

- `ConfigRegistry.ts` 维护组件 ID 与自定义配置区之间的注册映射。

## 维护边界

本目录适合放注册表、策略表和生命周期管理器，不适合放 Vue 渲染逻辑、业务 API 请求或页面级状态流转。

## 审查发现

当前目录只有一个注册表文件，职责集中。风险在于未来新增配置区时绕过注册入口，导致编辑器无法统一审查可配置能力。

## 重构建议

如果注册项继续增多，可以补充类型化注册描述和只读查询接口，减少调用方直接操作内部 Map 的可能性。

## 验证建议

新增注册能力后，运行交互系统组件测试，并手工验证对应组件在可视化编辑器中能正确展示配置区。
