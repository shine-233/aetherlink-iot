# 前端枚举目录

## 目录定位

`frontend/src/enum` 存放前端全局可复用枚举入口，用于汇总跨模块共享的常量枚举。

## 文件用途

- `index.ts` 是当前枚举导出入口。

## 维护边界

只放跨模块共享且稳定的枚举。页面私有枚举、接口响应字典和后端动态字典不应随意沉淀到这里，避免形成难以维护的全局常量池。

## 审查发现

当前目录很小，适合作为全局枚举边界。后续若枚举增多，需要区分“协议枚举”“UI 枚举”和“页面私有常量”。

## 重构建议

可以在枚举数量增长后按领域拆分文件，并在 `index.ts` 中只做显式导出，避免隐式导出造成命名冲突。

## 验证建议

调整枚举值时，检查后端协议、国际化文案、表单选项和测试 fixture 是否同步。仅新增 README 时无需运行测试。
