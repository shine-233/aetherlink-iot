# 西班牙语语言包

## 目录职责

本目录保存西班牙语界面文案，供前端在 `es-es` 语言环境下展示页面内容。它需要与其他语言包保持相同文件集合和 key 结构，确保切换语言后页面功能不受影响。

## 文件关系

目录内 JSON 文件按业务域拆分，并应与 `zh-cn`、`en-us`、`fr-fr` 目录中的同名文件一一对应。业务代码通过统一的 i18n key 读取文案，因此这里的结构稳定性比单个翻译内容更重要。

## 重点文件

- `common.json`：通用交互文案，容易被多个页面复用。
- `route.json`：西班牙语菜单和路由标题，需与路由配置保持同步。
- `device_template.json`：物模型相关文案，需要重点检查技术术语和表单提示。
- `visual-editor.json`：可视化编辑器文案，需要关注标签长度。
- `rdi.json`：RDI 业务文案，建议由理解业务语境的人复核。

## 审查建议

- 问题描述：西班牙语文本通常比中文和英文更长，可能导致按钮、表格列和卡片标题换行或溢出。
- 改进方案：在语言包审查中增加 UI 展示检查，重点覆盖菜单、表单、弹窗和可视化编辑器侧栏。
- 实施步骤：先用键一致性脚本确认没有缺键；再选择物模型、自动化、可视化编辑器等页面进行截图验收；最后修正过长文案或调整组件布局。
- 预期效果：减少语言切换后的布局问题，提升多语言界面的可用性。

## 使用注意

- 不要只修改本目录而忘记其他语言目录的同名 key。
- 技术缩写、协议名、变量占位符和接口枚举值必须保持原样。
- 涉及业务术语的翻译应优先参考产品术语表，而不是直接逐词翻译。
