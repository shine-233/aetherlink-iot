# 法语语言包

## 目录职责

本目录保存法语界面文案，供前端在 `fr-fr` 语言环境下展示菜单、页面、表单、提示和业务状态。该目录主要服务国际化展示、语言切换验证和公开项目的多语言完整性。

## 文件关系

本目录下的 JSON 文件应与其他语言包保持同名和同 key 结构。业务代码不应直接依赖某个语言目录的文件路径，而应通过统一 i18n 注册逻辑加载当前语言包。

## 重点文件

- `basic.json`、`common.json`：基础交互文案，修改影响范围广。
- `route.json`：菜单和路由标题，需与前端路由配置同步。
- `device_template.json`：物模型相关法语文案，需重点关注字段含义和校验提示。
- `visual-editor.json`：可视化编辑器文案，需检查长文本在看板布局中的显示效果。
- `rdi.json`：RDI 相关文案，应与业务文档中的术语保持一致。

## 审查建议

- 问题描述：法语文案存在性别、复数、缩写和长文本展示问题，简单机器翻译可能造成语义不自然。
- 改进方案：将语言包审查拆为结构校验和语义复核两层，先保证不缺 key，再由熟悉业务语境的人复核重点页面。
- 实施步骤：增加自动化 key 对齐检查；整理设备、告警、自动化、面板等高频术语；对公开演示路径做截图检查。
- 预期效果：提升法语界面的专业度，并降低语言切换后出现原始 key 或布局错位的风险。

## 使用注意

- 保留 `{name}`、`{count}` 等占位符，不要翻译或删除。
- 协议名、产品名、接口枚举值通常保持原文。
- 删除或改名 key 前必须同步搜索调用方和其他语言包。
