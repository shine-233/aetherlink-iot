# icon 插件目录

## 目录定位

`frontend/src/plugins/icon` 封装前端图标清单，供权限菜单、配置面板和动态图标选择控件复用。

## 文件用途

- `icons.ts` 维护图标集合，是权限图标选择器和配置面板共用的主清单。

## 维护边界

本目录只维护图标清单，不应放业务菜单、权限判断、示例页面或路由逻辑。新增图标时应保持命名稳定，避免破坏菜单、按钮和动态渲染中的引用。

## 审查发现

目录规模很小，但图标命名常被路由、菜单和低代码配置间接引用。随意改名比改样式风险更高。

## 重构建议

后续可以补充图标名称清单生成脚本或类型声明，让调用方在编译期发现不存在的图标名。


## 验证建议

新增或重命名图标后，检查菜单、按钮、物料预览和动态配置中是否仍能正常渲染。仅新增 README 时无需运行构建。
