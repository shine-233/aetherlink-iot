# router guard 测试目录

## 目录定位

`frontend/src/router/guard/__tests__` 保存路由守卫的单元测试，验证移动端布局、权限跳转和守卫分支的稳定性。

## 文件用途

- `mobile.test.ts` 覆盖移动端 guard 相关行为。
- `permission.test.ts` 覆盖权限 guard 相关行为。

## 维护边界

本目录只测试 guard 层输入输出和跳转决策，不应把页面组件渲染、后端权限接口细节或真实浏览器 E2E 流程塞入这里。

## 审查发现

测试目录与 guard 源码贴近，适合保护近期修复过的路由兼容逻辑。风险是 mock 与真实路由表漂移。

## 重构建议

如 guard 分支继续增加，建议建立共享 route fixture，减少每个测试重复构造路由对象并降低断言漏项。

## 验证建议

修改 guard 后运行本目录测试，并对登录跳转、移动端布局排除项、权限拒绝和白名单路由做 smoke 验证。
