# router routes 测试目录

## 目录定位

`frontend/src/router/routes/__tests__` 保存路由表契约测试，用于确认生成路由、兼容别名和关键页面入口没有被静态改动破坏。

## 文件用途

- `route-coverage-contract.test.ts` 覆盖路由清单与覆盖契约。

## 维护边界

本目录只维护路由结构契约，不替代页面渲染测试或 Playwright E2E。新增断言应聚焦路由是否存在、路径是否兼容、元数据是否满足导航要求。

## 审查发现

当前测试文件职责明确，适合守住 AetherLink IoT 的旧路径兼容和管理端入口。风险是路由生成规则变化后测试阈值未同步审查。

## 重构建议

可将关键路径清单抽成命名 fixture，区分产品必需路由、兼容别名和低优先级示例路由，减少阈值式断言的误导。

## 验证建议

修改路由表后运行该契约测试，并在浏览器中抽查登录后导航、管理路由和 ThingsVis 相关入口。
