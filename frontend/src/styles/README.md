# 前端样式目录

## 目录定位

`frontend/src/styles` 保存前端全局样式入口和样式分层目录，负责基础重置、动效、滚动条、进度条和 SCSS 工具样式。

## 文件用途

- `css/` 存放普通 CSS 文件，例如 reset、transition 和 nprogress 样式。
- `scss/` 存放 SCSS 全局样式、mixin 和局部工具样式。

## 维护边界

本目录只维护全局或跨页面共享样式。页面私有样式应优先留在页面组件或模块目录中，避免全局选择器影响不可预期的业务页面。

## 审查发现

样式父目录缺少总览说明，容易让全局样式继续扩散。当前子目录边界可进一步通过 README 固化。

## 重构建议

后续可以建立全局样式变更清单，明确哪些文件允许写标签选择器、哪些文件只允许变量或 mixin，减少样式串扰。

## 验证建议

修改全局样式后，至少抽查登录页、管理页、设备页、可视化编辑器和移动端布局。仅新增 README 时无需运行构建。
