# 全局 CSS 目录

## 目录定位

`frontend/src/styles/css` 保存不需要 SCSS 编译能力的全局 CSS 文件，主要承担浏览器默认样式重置、页面过渡和第三方进度条样式。

## 文件用途

- `global.css` 放全局基础样式。
- `reset.css` 统一浏览器默认样式。
- `transition.css` 定义页面或组件过渡类。
- `nprogress.css` 定义顶部加载进度条样式。

## 维护边界

本目录的选择器影响全局，新增规则必须避免使用过宽的业务类名。组件局部样式、页面布局样式和主题变量不应放入这里。

## 审查发现

现有文件职责较清晰。主要风险是为了修某个页面样式而修改 reset 或 global，造成其他页面隐性回归。

## 重构建议

可逐步把页面定制样式迁回页面或组件，将本目录保留为真正的基础样式层。

## 验证建议

修改 CSS 后进行多页面视觉抽查，重点看滚动、过渡、表单、表格和第三方进度条。仅新增 README 时无需运行构建。
