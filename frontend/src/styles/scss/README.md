# 全局 SCSS 目录

## 目录定位

`frontend/src/styles/scss` 保存需要 SCSS 能力的全局样式、mixin 和共享工具样式。

## 文件用途

- `_mixins.scss` 提供可复用 mixin。
- `global.scss` 保存 SCSS 版本的全局样式。
- `grid-background.scss` 保存网格背景样式。
- `scrollbar.scss` 保存滚动条样式。

## 维护边界

本目录适合放变量组合、mixin 和跨模块视觉基础设施，不应放具体页面业务样式。新增 mixin 前应确认至少有多个调用场景。

## 审查发现

SCSS 文件数量不多，适合继续保持基础设施定位。需要注意滚动条和网格背景这类全局视觉效果对编辑器、看板和移动端的影响。

## 重构建议

后续可把 mixin 文档化，说明输入参数、输出选择器和适用范围，避免调用方误用造成样式泄漏。

## 验证建议

修改 SCSS 后抽查可视化编辑器、表格页面、暗色/亮色主题和滚动容器。仅新增 README 时无需运行构建。
