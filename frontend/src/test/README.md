# 前端测试辅助目录

## 目录定位

`frontend/src/test` 保存 Vitest 和组件测试共享的辅助代码，用于建立稳定的测试环境、国际化 mock 和提升前端单测可维护性。

## 文件用途

- `setup.ts` 配置测试运行时的全局环境。
- `i18n.ts` 提供测试用国际化支持。
- `hoisted-mocks.ts` 提供需要提升声明的 mock。

## 维护边界

本目录只放跨测试共享的基础设施。单个模块专用 mock 应留在对应测试文件或模块测试目录，避免全局 setup 变成隐性依赖。

## 审查发现

目录职责明确，但全局测试辅助一旦增加副作用，会影响大量测试并让失败难以定位。

## 重构建议

新增全局 mock 前应优先评估是否能局部 mock。若必须全局化，应在 README 或文件注释中说明影响范围和退出条件。

## 验证建议

修改本目录后运行一组代表性 Vitest，包括路由、service、core 组件和 store 相关测试。仅新增 README 时无需运行测试。
