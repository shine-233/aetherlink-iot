# 前端主题目录

## 目录定位

`frontend/src/theme` 保存前端主题配置和主题变量，是应用视觉风格、暗色模式或 UI 库主题覆盖的基础入口。

## 文件用途

- `settings.ts` 定义主题配置项。
- `vars.ts` 定义主题变量或变量映射。

## 维护边界

本目录只维护主题级配置，不应放页面样式、组件局部样式或业务状态。主题变量变更需要考虑全站视觉一致性和第三方 UI 组件覆盖关系。

## 审查发现

目录很小，但影响范围大。变量命名或默认值改动可能同时影响管理端、可视化编辑器和移动端页面。

## 重构建议

后续可以补充主题变量清单和使用方索引，明确哪些变量属于产品品牌、布局、状态色或组件覆盖。

## 验证建议

修改主题后抽查亮色/暗色、主色切换、表单、表格、弹窗和可视化编辑器。仅新增 README 时无需运行构建。
