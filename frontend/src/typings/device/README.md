# device 类型声明目录

## 目录定位

`frontend/src/typings/device` 保存设备领域的前端 TypeScript 声明，用于统一设备、遥测、属性、事件或配置相关结构。

## 文件用途

- `device.d.ts` 定义设备领域共享类型。

## 维护边界

本目录只放设备领域类型契约，不应放运行时代码、接口请求实现或页面状态。新增字段时应确认后端响应、前端 service 和页面使用方是否一致。

## 审查发现

类型声明集中，便于复用。主要风险是把临时页面字段提升为全局设备类型，导致领域模型越来越模糊。

## 重构建议

后续可按设备基础信息、遥测属性事件、配置模板和共享状态拆分声明文件，并通过显式导出说明适用边界。

## 验证建议

修改类型后运行 TypeScript 检查或受影响模块的 ESLint/Vitest，并抽查设备管理、设备详情和可视化选择器。
