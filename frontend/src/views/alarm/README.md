# 告警视图

`frontend/src/views/alarm` 承载告警消息、通知组、通知记录和 RDI 告警概览入口。

## 目录职责

- `warning-message/` 管理告警配置、告警消息列表和新增编辑弹窗。
- `notification-group/` 管理通知组、通知成员和通知方式。
- `notification-record/` 展示通知发送历史记录。
- `rdi-overview/` 复用仪表盘 RDI 概览页面，作为告警域入口。

## 维护注意

- 告警状态、严重级别和通知方式需要与后端枚举保持一致。
- 告警确认、重置、启停和通知组编辑属于高影响操作，改动时需要保留用户反馈和失败态。

## 重构建议

- 可继续把告警字段映射、通知成员分页和弹窗表单拆成更小的可测试单元。
- 与仪表盘共用 RDI 概览时，应明确哪些行为属于告警域包装，哪些属于 dashboard 原始能力。
