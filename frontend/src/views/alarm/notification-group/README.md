# 告警通知组

`notification-group` 目录负责通知组列表、成员维护和通知方式配置。

## 目录职责

- `index.vue` 管理通知组查询、分页、详情加载和删除确认，并挂载共享告警邮件模板管理器；该路由面向 `TENANT_ADMIN`，模板 API 使用当前 claims 的租户作用域。
- `utils.ts` 存放通知成员搜索、分页和选项组装逻辑。
- `components/` 提供成员类型数据和通知组编辑弹窗。
- `__tests__/` 覆盖列表、工具函数关联行为和组件交互。

## 维护注意

- 通知组成员可能来自不同成员类型，改动时同步选项、分页和删除逻辑。
- 保存通知组后需要统一刷新列表，避免弹窗内外状态不一致。
- 通知组与邮件模板是相邻但不同的业务对象：通知组决定通知方式/目标，模板只包装最终主题和正文，不能参与收件人推断。
- 页面不得自行传入或切换模板 `tenant_id`；`TENANT_USER` 和未知 authority 由后端模板服务统一拒绝。
