# 通知组组件测试说明

本目录覆盖通知组子组件的基础交互合同，重点验证成员通知方式选择、成员删除/更新回调，以及新增编辑通知组弹窗的标题、表单默认值和显隐事件。

## 测试覆盖目标

- `member-type-data.test.ts` 覆盖成员类型选择器的默认渲染、初始选中值、删除和更新事件。
- `table-action-modal.test.ts` 覆盖通知组新增/编辑弹窗的表单模型、标题计算、关闭事件和提交前状态。

## 维护规则

- 修改成员字段、通知方式枚举或弹窗必填项时，必须同步调整 mock 数据和表单断言。
- 测试应继续使用组件替身隔离 Naive UI，只验证本组件对外事件和表单契约。

## 已知缺口

- 尚未覆盖真实后端校验失败、成员分页加载和通知方式权限边界。
