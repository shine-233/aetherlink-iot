# 告警消息组件测试说明

本目录覆盖告警消息页的关键组件和辅助函数，重点验证告警配置解析、新增编辑弹窗、维护说明和通知组下拉加载。

## 测试覆盖目标

- `alarm-configuration.helpers.test.ts` 覆盖 remark JSON 解析、动作字段、确认状态和严重级别映射。
- `alarm-configuration.test.ts` 覆盖告警历史加载、确认、重置和维护弹窗提交。
- `new-information.test.ts` 覆盖告警配置列表、启停按钮、分页、编辑和删除入口。
- `pop-up.test.ts` 覆盖新增/编辑弹窗、通知组分页加载、表单回填和提交 payload。

## 维护规则

- 修改告警 remark 结构、严重级别枚举或通知组字段时，必须同步更新辅助函数测试。
- 组件测试应优先断言用户可见结果和提交 payload，不要只检查内部变量。

## 已知缺口

- 尚未覆盖真实设备告警流入、后端维护窗口冲突和通知组远端加载失败的完整用户提示。
