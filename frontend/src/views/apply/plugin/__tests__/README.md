# 应用插件页面测试说明

本目录覆盖插件服务列表和路由级接入合同，保证插件服务能查询、分页、新增、编辑、配置和删除。

## 测试覆盖目标

- `index.test.ts` 覆盖插件服务列表加载、添加、编辑、配置弹窗、删除和分页。
- `form.test.ts` 补充动态表单在插件页路径下的 schema 解析合同。

## 维护规则

- 修改插件服务 API、分页结构或操作列时，需同步更新接口 mock 与断言。
- 页面测试应区分插件服务和协议服务，不要混用 `apply/service` 的接口模型。

## 已知缺口

- 尚未覆盖真实配置保存后的回读校验、删除失败提示和插件服务权限控制。
