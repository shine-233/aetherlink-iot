# 协议服务页面测试说明

本目录覆盖协议服务列表页及其历史兼容测试，确保服务列表加载、分页、新增编辑和删除流程可回归。

## 测试覆盖目标

- `index.test.ts` 覆盖协议服务列表初始化、添加、编辑、删除成功/失败和分页刷新。
- `service-index.test.ts` 覆盖查询模型、表格列、分页和弹窗状态的页面合同。
- `table-action-modal.test.ts` 覆盖同路径组件弹窗的基础标题、默认值和事件。

## 维护规则

- 调整协议服务 API 或列表字段时，需要同时检查两个页面测试是否存在重复断言并保持一致。
- 保持删除失败分支断言，避免误把失败响应当作成功刷新。

## 已知缺口

- 仍存在部分重复覆盖，后续可合并为一个更清晰的列表页测试和一个组件测试。
