# 场景联动列表页

## 目录职责

`frontend/src/views/automation/scene-linkage` 负责展示和管理场景联动规则列表，是联动规则的上游入口页。

## 文件关系

- `index.vue`
  - 路由页面入口，负责列表页装配。
- `modules/dataList.vue`
  - 列表数据、状态展示、操作按钮和分页逻辑主实现。
- `service/api/automation.ts`
  - 提供联动规则列表、启停、删除和详情接口。

## 重点文件

- `index.vue`
  - 页面入口壳层。
- `modules/dataList.vue`
  - 联动规则列表与操作主逻辑。

## 当前静态审查结论

### 发现的问题

- 启停、删除、分页和编辑跳转都依赖后端状态字段和列表刷新时序，若字段解释不清，前后端很容易出现“看起来切换了，实际状态没对齐”的问题。

### 改进方案

- 继续补页面和列表模块的中文说明，明确状态字段、列表刷新和操作边界。
- 把状态切换和删除确认流程中的重复逻辑收敛成局部 helper。

### 建议实施步骤

1. 先补齐列表页与 `dataList.vue` 的关键状态流说明。
2. 再识别启停、删除和分页中的重复逻辑，逐步提炼 helper。
3. 静态批次结束后，再统一验证列表操作与编辑跳转链路。

### 预期效果

- 联动规则列表页更容易维护，状态切换和删除流程更方便审查。
- GitHub 浏览者能更快理解联动规则列表与编辑页之间的关系。
