# 普通自动化场景管理页

## 目录职责

`frontend/src/views/automation/scene-manage` 负责普通自动化场景的列表管理与入口操作，覆盖列表筛选、启停切换、删除确认、编辑跳转和详情入口。

它属于自动化域的上游列表页，直接决定维护者如何进入场景编辑链路，也是运营侧最常接触的自动化入口之一。

## 文件关系

- `index.vue`
  - 场景管理页面入口，负责列表加载、操作按钮和跳转流程。
- `service/api/automation.ts`
  - 提供场景列表、启停、删除、日志和详情相关接口。
- `../scene-edit`
  - 承接普通自动化场景的新增与编辑页面。

## 重点文件

- `index.vue`
  - 场景列表、筛选参数、状态切换和编辑入口的协调中心。

## 当前静态审查结论

### 发现的问题

- 列表筛选、状态切换、删除确认和编辑跳转都集中在同一个页面壳层，后续继续叠加功能时容易变厚。
- 自动化列表页与编辑页之间通过路由参数和接口字段耦合，字段一旦漂移，问题往往会延迟暴露。

### 改进方案

- 继续补齐 `index.vue` 文件头和关键状态流说明，明确列表筛选、启停和跳转边界。
- 逐步把筛选参数归一化、启停切换和删除确认收敛成局部 helper，降低主页面脚本复杂度。

### 建议实施步骤

1. 先补齐页面文件头与接口字段说明。
2. 再识别列表筛选和操作确认里的重复逻辑，逐步抽 helper。
3. 静态批次结束后，再统一验证启停、删除和编辑跳转链路。

### 预期效果

- 自动化入口页更易维护，状态切换与列表逻辑更容易局部审查。
- GitHub 浏览者能先通过 README 建立“列表页 -> 编辑页”的路径理解。
