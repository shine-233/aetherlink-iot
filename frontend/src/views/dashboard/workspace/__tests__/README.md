# frontend/src/views/dashboard/workspace/__tests__ 目录说明

## 目录职责

本目录存放相邻页面或组件的 Vitest 单元测试，用来保护关键渲染、交互和边界行为。

## 测试覆盖目标

- 验证相邻页面或组件能渲染关键内容、触发主要交互，并处理空状态、错误状态或权限差异。
- 使用稳定 mock 隔离 store、router、接口和第三方 UI 组件，让失败原因容易定位。
- 优先断言用户可见结果和对外调用，不把测试降级成简单的挂载或快照检查。

## 维护规则

- 修改相邻页面行为时，先更新或补充对应用例，不要直接删除失败断言。
- 新增 mock 时保持命名清晰，并在用例中说明它代表的路由、接口或状态输入。
- 复杂准备逻辑应抽成本测试目录内的 helper，避免每个用例重复搭建环境。

## 已知缺口

- 单元测试不能替代真实后端、API 自动化或 Playwright E2E，只能证明组件边界内的行为。
- 图表细节、真实权限链路和跨页导航仍需要更高层级测试补证。
