# 设备 / 设备配置 / 组合函数

## 目录职责

本目录负责 设备 / 设备配置 / 组合函数 相关的前端页面、业务组件和局部辅助逻辑，是 `frontend/src/views/device/config/composables` 范围内的维护入口。

## 文件关系

- `use-market-auth.ts`: 读写设备物模型市场的 `market_token` 会话态，并提供登录态判断、设置、清理和读取方法。
- `useMarketTemplateInstall.ts`: 处理市场模板安装、重复安装、认证失败和缺少插件的提示与回调；调用方负责注入 API、登录弹窗和国际化依赖。
