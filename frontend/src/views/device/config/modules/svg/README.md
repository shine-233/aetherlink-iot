# Device Config Module SVG Assets

## 目录职责

`frontend/src/views/device/config/modules/svg` 保存设备配置模块专用的静态 SVG 资源，目前用于物模型市场或配置展示的默认封面。

## 文件关系

- `default-config.svg` 是模块局部资源，不属于全局图标系统。
- 上级模块组件在缺少远程封面或模板图片时可引用这里的默认资源。
- 资源行为由组件测试间接覆盖，例如默认封面回退应在模板卡片测试中验证。

## 重点文件

- `default-config.svg`: 设备配置/物模型市场默认展示图。

## 审查建议

替换 SVG 时保持文件名和引用路径稳定，避免破坏模板卡片的默认封面回退。若新增更多资源，优先确认是否真是模块私有资产；跨页面复用的图标应放到项目统一资产位置。
