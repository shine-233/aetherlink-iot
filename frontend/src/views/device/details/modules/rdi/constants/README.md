# RDI 常量目录

## 目录职责

`frontend/src/views/device/details/modules/rdi/constants` 保存 RDI 操作视图共用的字段标签、系统扩展字段和本地化相关常量定义。

## 文件关系

- `rdi-labels.ts`
  - RDI 标签和字段定义的集中来源。
- 常量被 RDI 操作视图、composable 和测试共同引用。

## 静态审查建议

- 问题：常量层字段一旦漂移，通常会连带影响展示文案、字段匹配和测试断言。
- 改进：新增或调整字段时，继续同步核对语言资源、类型导出和使用方说明。
- 预期效果：RDI 字段体系更稳定，维护者更容易判断改动影响面。
