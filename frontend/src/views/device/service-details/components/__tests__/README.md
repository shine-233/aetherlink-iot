# 设备 / 服务详情 / 组件 / 测试

## 目录职责

本目录存放 设备 / 服务详情 / 组件 的 Vitest 测试，用来守住页面渲染、关键交互、接口 mock 和业务状态流转的回归边界。

## 测试覆盖目标

- 覆盖用户能看到或能触发的主流程，包括列表查询、表单提交、弹窗打开关闭、路由参数读取和错误提示。
- 覆盖接口返回为空、失败或字段缺失时的安全降级，避免只验证 happy path。
- 覆盖与权限、租户、设备/产品标识、ThingsVis 配置等业务关键字段有关的断言。

## 维护规则

- 新增页面行为时，优先补用户可见结果和提交载荷断言，不只断言组件成功挂载。
- Mock 数据字段要贴近真实 API；接口字段变更时同步更新 fixture、断言和 README。
- 测试文件必须保留四字段中文文件头，说明覆盖目标和后续重构方向。

## 已知缺口

- 这些测试主要是视图层单元/组件测试，不能替代真实后端、浏览器 E2E 或权限链路验证。
- 若流程依赖定时器、地图、编辑器或第三方可视化 SDK，需要额外补集成级用例确认真实运行行为。
