# 设备分享落地页

## 目录职责

`frontend/src/views/device/share` 负责处理设备分享链接落地页，读取分享 token、执行接受分享流程，并将用户导向共享列表或设备详情。

## 文件关系

- `index.vue`
  - 从路由参数读取 `share_token`，处理接受分享与结果展示。
- `service/api/rdi.ts`
  - 提供接受分享接口。
- `../shared-with-me`
  - 承接成功后的内部设备查看列表。

## 静态审查建议

- 问题：这是外部入口页面，token 缺失、重复接受、分享失效和接口失败分支都很敏感。
- 改进：补充更清晰的页面文件头、错误分支说明和稳定的测试挂点说明。
- 预期效果：分享落地链路更容易回归验证，也更方便定位外部入口问题。
