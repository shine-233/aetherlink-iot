# 共享给我的设备页

## 目录职责

`frontend/src/views/device/shared-with-me` 负责展示当前用户收到的共享 RDI 设备列表，并提供进入设备详情或后续操作的入口。

## 文件关系

- `index.vue`
  - 负责共享设备列表查询、空状态、加载态和详情跳转。
- `service/api/rdi.ts`
  - 提供 shared-with-me 列表接口。
- `../share`
  - 负责外部分享链接接入；本目录承接分享成功后的内部查看场景。

## 静态审查建议

- 问题：分享链路天然带权限边界，列表页若对空态、重复分享或刷新时序处理不清，容易出现体验与权限结论不一致。
- 改进：继续补文件头和状态流说明，明确列表加载、空态和详情跳转边界。
- 预期效果：分享链路更容易维护，也更方便和 `share` 落地页联动审查。
