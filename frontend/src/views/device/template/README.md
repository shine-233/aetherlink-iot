# 物模型页

## 目录职责

`frontend/src/views/device/template` 承载物模型列表页、物模型编辑向导、模型定义以及 Web/App ThingsVis 图表配置，是物模型从列表检索到分步配置的前端入口。

## 文件关系

- `index.vue`
  - 列表页入口，负责查询、分页、卡片/表格切换和编辑弹窗调度。
- `utils.ts`
  - 提供模板基础信息默认值、表单规则、物模型标签与附加信息解析工具。
- `components/template-modal.vue`
  - 编排新增/编辑模板的五步向导。
- `components/step/`
  - 存放模板基础信息、物模型定义、图表配置和完成页等步骤组件。
- `__tests__/`
  - 保存模板页面测试资源。

## 当前静态审查结论

- 问题：模板页同时承载列表、向导、物模型和 ThingsVis 图表配置，功能聚合度高，后续继续加能力时容易继续变厚。
- 改进：继续明确新增/编辑模式、图表配置归一化和物模型编辑边界，优先做小步静态收敛。
- 预期效果：模板页结构更清晰，后续新增模板能力时更容易判断改动落点。
