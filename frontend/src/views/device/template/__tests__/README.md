# Thing Model Page Tests

## 目录职责

覆盖物模型列表页入口的查询、分页、删除、标签展示、视图切换和编辑弹窗触发行为。

## 文件关系

- `index.test.ts` 覆盖列表页基础初始化和主要交互路径。
- `template.test.ts` 覆盖列表页更完整的成功/失败删除、分页、标签拆分和列定义行为。
- 两个测试都通过 mock 物模型 API、路由和 hooks，避免依赖真实后端。

## 重点文件

- `template.test.ts`: 覆盖面更完整，是列表页行为回归的主要入口。
- `index.test.ts`: 轻量初始化与基础交互验证入口。

## 审查建议

- 页面新增查询参数时，要同时确认 API mock 断言和重置行为。
- 删除流程改动时，同时覆盖成功提示、失败提示和刷新调用。
- 如果列表页切换到新的 UI 组件，优先保留用户可见行为断言，避免只断言内部状态。
