# 物模型组件层

## 目录职责

`frontend/src/views/device/template/components` 保存物模型页面的复合组件，包括模型编辑向导弹窗、步骤组件、ThingsVis 图表配置入口和模型静态图形资源。

## 文件关系

- `template-modal.vue`
  - 上层向导容器，按步骤动态加载 `step/` 下的配置组件。
- `step/`
  - 承接物模型基础资料、模型定义、Web/App 图表配置、完成页等业务步骤。
- `svg/`
  - 提供物模型列表或空态展示使用的静态图标资源。
- `__tests__/`
  - 覆盖组件容器层的向导状态和标题逻辑。

## 当前静态审查结论

- 问题：向导步骤和 ThingsVis 图表配置聚在一个组件层，props / emits 契约一旦漂移，回归排查会比较痛苦。
- 改进：继续保持步骤 ID、组件映射和子组件事件契约在 README 与文件头中同步记录。
- 预期效果：物模型组件层更容易局部维护，也更方便后续按步骤补测试或重构。
