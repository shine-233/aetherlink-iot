# Thing Model SVG Assets

## 目录职责

存放物模型视图使用的静态 SVG 资源，当前主要用于模型卡片或默认展示图标。

## 文件关系

- `default-template.svg` 是默认物模型图示资源。
- 上层页面通过图片路径或静态资源引用展示该图标。

## 重点文件

- `default-template.svg`: 当前唯一物模型默认图标。

## 审查建议

- 修改 SVG 时只调整视觉资源，不应混入组件逻辑。
- 如果新增多个物模型图标，建议在 README 中记录使用场景和引用方。
- 注意 SVG 内注释当前存在历史编码痕迹，若清理需单独做资源文本修复并验证展示。
