# Home Test Notes

This directory covers the current Home entry and ThingsVis fallback path.

Removed tests should not be reintroduced only to cover deleted template-only
modules. A Home test counts as useful only when the source is reachable from the
current customer entry path or protects a live fallback contract.

The old standalone Home chart modules were removed for the same reason: the
current Home page no longer mounts them, and Dashboard Analysis owns its own
operations charts.
