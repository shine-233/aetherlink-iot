# 通知配置组件测试说明

本目录覆盖系统通知配置的邮件、短信和推送组件，保证配置加载、编辑保存和特殊字段处理稳定。

## 测试覆盖目标

- `email.test.ts` 覆盖邮件服务配置加载、默认模型、调试弹窗、提交保存和刷新。
- `short-message.test.ts` 覆盖短信服务配置加载，以及保存时不回传后端 echo 配置字符串。
- `push-notification.test.ts` 覆盖推送 URL 加载、null 哨兵值处理、提交保存和刷新。

## 维护规则

- 修改通知服务编码、配置 JSON 字段或 null 哨兵值时，必须同步更新测试。
- 保存 payload 要显式断言，避免把后端回显字段重新提交造成配置污染。

## 已知缺口

- 尚未覆盖真实发送调试、认证失败、短信供应商差异和推送服务连通性。
