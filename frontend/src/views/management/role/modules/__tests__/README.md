# 后台角色组件测试说明

本目录覆盖后台角色管理的列设置、权限弹窗和新增编辑弹窗。

## 测试覆盖目标

- `column-setting.test.ts` 覆盖可拖拽列设置、选中状态和 `update:columns` 输出。
- `edit-permission-modal.test.ts` 覆盖权限树选择、标题、节点转换和关闭事件。
- `table-action-modal.test.ts` 覆盖角色新增编辑弹窗标题、模型、规则和显隐绑定。

## 维护规则

- 修改角色字段、权限树结构或列配置时，需同步更新对应组件测试。
- 权限树节点转换应保持独立断言，避免只靠页面集成测试发现回归。

## 已知缺口

- 尚未覆盖真实权限树远端加载失败和拖拽排序持久化。
