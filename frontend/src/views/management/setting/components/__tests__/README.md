# 系统设置组件测试说明

本目录覆盖系统设置下的账号、邮箱、品牌、数据清理、功能开关和告警邮箱组件。

## 测试覆盖目标

- `account-email-setting.test.ts` 覆盖当前邮箱、验证码发送、表单重置和设备迁移计数。
- `account-profile-setting.test.ts` 覆盖账号资料加载、语言映射、手机号兼容和密码表单。
- `branding-setting.test.ts` 覆盖品牌配置加载、赋值、保存前校验和异常数据处理。
- `data-clear-setting.test.ts` 覆盖数据清理策略列表、默认模型、编辑数据和加载失败降级。
- `function-setting.test.ts` 覆盖功能开关加载、本地缓存和切换保存。
- `warning-email-setting.test.ts` 覆盖告警邮箱加载、解析、去重和异常响应处理。

## 维护规则

- 修改设置项字段、后端配置 JSON 或本地缓存 key 时，必须同步更新对应组件测试。
- 账号和邮箱相关测试不要写入真实个人信息，使用稳定 mock 数据即可。

## 已知缺口

- 尚未覆盖真实文件上传、品牌预览、验证码倒计时、功能开关跨页面生效和数据清理危险操作确认。
