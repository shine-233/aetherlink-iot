# 后台用户组件测试说明

本目录覆盖后台用户管理的列设置、密码弹窗和新增编辑用户弹窗。

## 测试覆盖目标

- `column-setting.test.ts` 覆盖列设置列表、选中状态、拖拽输出和过滤后的列配置。
- `edit-password-modal.test.ts` 覆盖密码弹窗显隐、只读邮箱、默认模型、规则和回填。
- `table-action-modal.test.ts` 覆盖用户新增编辑弹窗标题、默认字段、校验规则、显隐绑定和区域字段。

## 维护规则

- 修改用户字段、列配置、密码规则或区域信息时，需同步更新对应组件测试。
- 密码测试只使用 mock 数据，不应记录真实密码或真实邮箱。

## 已知缺口

- 尚未覆盖真实区域级联加载失败、密码强度服务端校验和列设置持久化。
