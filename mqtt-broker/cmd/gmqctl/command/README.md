# gmqctl 命令入口

## 目录定位

这个目录是 `gmqctl` 命令行工具的子命令注册层，负责把 broker 维护工具中的生成器命令挂到统一的 `gen` 命令树下。

## 文件用途

- `command.go`：定义 `gen` 命令，并注册 `gen-plugin` 插件模板生成命令。
- `gen-plugin/`：实际的插件代码模板生成器实现，包含命令参数、模板和单元测试。

## 生成物、示例、测试数据边界

本目录本身不是生成物目录，也不直接保存生成结果。真正的模板输出由 `gen-plugin` 子命令写入调用方指定的输出目录。

## 审查发现

- 当前目录只有命令编排逻辑，职责边界清楚。
- 目录此前缺少 README，阅读者需要进入子目录才能理解 `gen` 命令来源。
- 根命令没有单独测试，现有行为主要由子命令测试间接覆盖。

## 重构建议

- 如果后续增加更多生成器，可以保持“根命令只注册子命令”的边界，把参数解析和文件写入继续下沉到子包。
- 可补一个轻量测试，断言 `Gen` 命令挂载的子命令名称和帮助文本，防止 CLI 入口漂移。

## 验证建议

- 修改命令注册后运行：`go test ./cmd/gmqctl/command/... -count=1`。
- 修改 Go 文件后运行：`gofmt -w cmd/gmqctl/command/**/*.go`。
