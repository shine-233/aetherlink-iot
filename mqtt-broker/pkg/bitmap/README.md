# bitmap 位图工具包

## 目录职责

本目录提供 MQTT Broker 内部使用的轻量位图结构，用于以较小内存记录固定范围内的布尔状态或标记位。

## 文件关系

- `bitmap.go`：实现 `Bitmap` 结构、最大容量、创建、读取和写入方法。
- `bitmap_test.go`：验证边界大小、置位、清位和读取行为。

## 重点文件

- `bitmap.go`：核心实现文件，位移和边界判断错误会直接影响标记状态的准确性。

## 审查建议

- 问题描述：当前边界判断采用 `b.size < offset`，允许 `offset == size` 写入，调用方需要明确这是现有契约还是 off-by-one 兼容行为。
- 改进方案：后续如果要收紧边界，应先补齐 `offset == size`、`offset > size`、`size == 0` 的契约测试。
- 实施步骤：先确认业务调用方是否依赖最高位可写；再调整边界；最后运行 broker 相关包测试。
- 预期效果：减少位图边界语义不清导致的状态误判。

## 使用注意

- `New(0)` 会回退到 `MaxSize`，调用方不应把 `0` 当作空位图。
- `Set` 返回 `false` 表示越界或未写入，调用方如依赖写入成功应显式检查。
