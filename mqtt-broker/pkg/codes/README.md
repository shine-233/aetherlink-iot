# codes MQTT 原因码包

## 目录职责

本目录维护 MQTT v3/v5 连接和错误处理相关的原因码常量，并提供带原因字符串和用户属性的错误包装结构。

## 文件关系

- `codes.go`：定义 MQTT v3 CONNACK 返回码、MQTT v5 reason code、共享错误实例和 `Error` 类型。
- `codes_test.go`：验证共享错误实例、错误字符串和关键 code 别名保持稳定。

## 重点文件

- `codes.go`：协议常量属于外部契约，数值错误会影响客户端兼容性和错误诊断。

## 审查建议

- 问题描述：协议常量数量多且名称相近，手动维护容易引入拼写、数值或语义漂移。
- 改进方案：保留协议出处说明，并为新增 reason code 补充表驱动测试。
- 实施步骤：新增 code 时对照 MQTT 规范；补充 `Error` 字符串和共享错误实例测试；最后运行 `go test ./pkg/codes`。
- 预期效果：提高协议兼容稳定性，减少客户端解析错误。

## 使用注意

- 不要随意修改已有常量值；它们与 MQTT 协议字节值绑定。
- `ErrMalformed`、`ErrProtocol` 是共享错误实例，不应在调用方写入请求级动态详情。
