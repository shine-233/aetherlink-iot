# pidfile 进程文件包

## 目录职责

本目录提供 Broker 进程 PID 文件的创建、冲突检查和删除能力，用于避免同一路径下重复启动多个进程。

## 文件关系

- `pidfile.go`：跨平台公共逻辑，负责读取旧 PID、检查进程是否仍存在、创建目录并写入当前进程 ID。
- `pidfile_unix.go`：Linux/Unix 平台通过 `/proc/<pid>` 判断进程是否存在。
- `pidfile_darwin.go`：macOS 平台通过 `kill(pid, 0)` 判断进程是否存在。
- `pidfile_windows.go`：Windows 平台通过系统调用打开进程并读取退出码。
- `pidfile_test.go`：验证 PID 文件创建、冲突检查和删除行为。

## 重点文件

- `pidfile.go`：创建和删除 PID 文件的主入口，错误处理会影响 Broker 启停可靠性。
- 平台文件：`processExists` 的实现必须符合各平台系统语义，不能简单复用。

## 审查建议

- 问题描述：PID 文件逻辑依赖文件系统和平台进程查询，容易出现僵尸文件、权限不足或跨平台判断差异。
- 改进方案：保持公共逻辑和平台探测分离，并补充临时目录下的冲突/清理测试。
- 实施步骤：为 stale PID、活跃 PID、无权限路径和删除失败分别补测试或手工验证。
- 预期效果：降低重复启动、误删 PID 文件和平台兼容问题。

## 使用注意

- 创建成功后调用方应在进程退出时调用 `Remove()` 清理 PID 文件。
- 如果旧 PID 文件存在且进程仍活跃，`New` 会返回错误，调用方不应自动覆盖。
