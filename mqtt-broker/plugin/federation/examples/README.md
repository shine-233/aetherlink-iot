# federation examples

## 目录定位

这个目录保存 federation 插件的多节点本地示例配置，帮助开发者理解 broker 节点、gRPC/HTTP API、gossip 和插件加载顺序的组合方式。

## 文件用途

- `node1_config.yml`：本地 node1 示例，监听 MQTT `:1883`，并配置 federation、API 和日志。
- `node2_config.yml`：本地 node2 示例，使用另一组 MQTT/API/federation/gossip 端口。
- `join_node3_config.yml`：第三节点加入示例，保留可按需打开的 `retry_join` 配置。

## 生成物、示例、测试数据边界

这些文件是示例配置，不是生产配置，也不是自动生成物。示例里的 `127.0.0.1`、端口和节点名仅用于本地演示，多机部署时必须改成真实可路由地址。
