- ThingsVis：默认可视化路径已经是本地 `native-board` provider，不需要再重写一套面板系统。外部 ThingsVis 仅作为 optional profile 下的兼容 provider 保留；相关前端聚焦回归为 **9 个文件、113 个测试通过**。
- release preflight：新增 `preflight:local`，基于本地前端构建、真实 backend 和一次性 preview proxy 运行，并保证成功、失败和异常路径都清理 proxy；完整 `preflight:api-e2e` 发布门禁未被削弱。preflight 聚焦回归为 **29 passing**，连同 optional integration 部署契约复核为 **37 passing**。
- 其他外接依赖：默认 Compose 只包含 PostgreSQL、Redis、MQTT broker、backend 和 frontend，这些是核心基础设施，不适合自行重写。market、SMTP、map provider 均为外部可选能力：market 禁用或配置无效时 fail-closed；SMTP 生产路径不自动回退到可能泄漏验证码的本地适配器；地图 key 未配置时不加载外部脚本并显示本地降级视图。后端能力分类/market/邮件聚焦回归通过，地图降级为 **2 个文件、17 个测试通过**。
- 证据边界：本节是代码与聚焦测试复核，不覆盖或改写上面的历史 **49/53** E2E 快照。本轮没有重跑全量 E2E、完整真实账号发布门禁或可选外部服务的真实联调，因此不据此宣称 `release ready`。
- 尚未完成：设备容量、MQTT 吞吐、API p95、错误率、前端首载和各服务资源峰值仍需真实压测采集；这些运行证据不能用 mock 或静态代码结果代替。
